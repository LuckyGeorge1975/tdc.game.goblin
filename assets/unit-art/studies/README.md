# GOBLIN SIEGEBREAKER – Five Art-Direction Sets

Each folder contains the same reference unit in two production roles:

- `goblin-siegebreaker-icon.png` — transparent orthographic top view for the map and unit roster.
- `goblin-siegebreaker-library.png` — transparent three-quarter portrait for the unit library.

All files are 1254 × 1254 pixel PNGs with an alpha channel. They are visual decision assets and are not wired into the game.

## Shared generation specification

- Original autonomous heavy ground vehicle named GOBLIN SIEGEBREAKER.
- Predominantly straight edges, very few curves, no retro styling.
- No crew, text, letters, logos, borders or watermark.
- Icon: exact 90-degree overhead view, forward direction at the top, simplified planes, strong silhouette and readability at 64 pixels.
- Library: front-left isometric three-quarter view, complete vehicle visible and premium hard-surface rendering.
- Both variants: genuinely transparent background, no floor, scenery, hex tile or cast shadow.

## Sets

1. `01-modular-stealth-geometry` — graphite/petrol modules, cyan visor, lime status lights.
2. `02-industrial-exoframe` — exposed structural rails, steel panels and safety orange.
3. `03-monolithic-facet` — large black-green/titanium facets and amber-red sensor slit.
4. `04-autonomous-drone-corps` — flat warm-gray drone chassis and electric-blue sensors.
5. `05-aerospace-ground-force` — arrowhead lifting-body armor, broken white and coral-red lights.

Generated with the built-in ImageGen workflow using the corresponding concept image in `assets/concepts/` as a design reference.
