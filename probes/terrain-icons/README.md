# Twelve terrain type representatives (`goblin-nbg.13.2`)

`assets/terrain-icons/manifest.json` is the shared canonical ID → small icon → original PNG mapping for the later field info, legend and preview integration. It contains exactly the twelve terrain rule IDs. `forest.png`, `river-straight.png`, `road-straight.png` and `urban-s0.png` represent their **types only**; they do not choose a forest edge, connection or city variant for a map cell. The existing five mission bakes and SVG field fallback remain the map renderers.

The approved Content pin is `c01ecb80bcdd813772d1433d9ae63b39e54ef050`. The current published Content-main check at `2fdce6ac1be30e8b2a360250b37724586469e71c` has the same original image bytes. Source paths begin with `beratung-ui-ux/design-exports/uebergabe-karte/`. Export the `icons-terrain/` directory and `terrain-icons.json` separately using `tools/content-source.ps1 -Action Export -Commit 2fdce6ac1be30e8b2a360250b37724586469e71c -Path <source path>` from the project root. Pass the two reported ZIP paths to `probes/terrain-icons/export.py ICONS_ZIP MANIFEST_ZIP OUTPUT_DIR [--contact CONTACT_PNG]`. The output directory must be absent. Python needs Pillow with WebP support; this export used Pillow 12.3.0.

The exporter verifies the complete 35-file list, canonical ID/variant pairing, 256×296 RGBA dimensions, transparent corners and alpha range, and each original's byte count and SHA-256 against the pinned `probes/map-bake/RESULTS.json` source receipt. The manifest itself is hash pinned. It then downsamples the **entire** 256×296 canvas to 48×56 with LANCZOS and writes only twelve lossless WebPs. Decoded pixels, including alpha, are checked against the 48×56 PNG candidates before output. No retouch, crop or recoloring is applied.

The twelve PNG candidates total 59,638 bytes; the shipped lossless WebPs total 42,188 bytes. At this size, lossless WebP saves 17,450 bytes while preserving every downscaled color and alpha value. A lossy quality-90 probe totaled 18,188 bytes but changed colors, so it was not selected. There is no duplicate PNG set in the runtime assets. The individual sizes and hashes are in the generated manifest.

`contact-48px.png` compares each 48×56 PNG candidate with its decoded lossless WebP on light and dark grounds, displayed at native size. It is a review artifact under `probes/`, not loaded by the game. Check the full silhouettes and three close pairs: `water` versus `river`, `mountain` versus `ridge`, and `road` versus `bridge`. The road and river remain narrow overlays by design; `urban` is explicitly the s0 type representative. Independent visual acceptance remains with the asset tester.
